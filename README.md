# 🛍️ Retail Sales Analytics

A data analytics project built using **MySQL, Python, Pandas, and Matplotlib** to analyze retail sales data and generate business insights through SQL queries and visualizations.

---

## 📌 Project Overview

This project focuses on analyzing a retail sales dataset to identify sales trends, profitable regions, top-performing products, and customer segments.

The workflow includes:
- Importing CSV data into MySQL
- Writing SQL queries for business analysis
- Fetching data using Python
- Creating visualizations with Matplotlib
- Managing the project using Git and GitHub

---
